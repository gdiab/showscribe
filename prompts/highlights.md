# Key Highlights Generator

Extract 5-8 key highlights from this podcast episode transcript that showcase the most valuable content and insights.

## Requirements:

- **Actionable insights**: Practical advice listeners can implement
- **Memorable quotes**: Powerful or thought-provoking statements
- **Key takeaways**: Important lessons or conclusions
- **Specific details**: Include numbers, examples, or concrete details when available
- **Value-focused**: Prioritize content that provides genuine value to the audience

## Format Guidelines:

- Each highlight should be 1-2 sentences maximum
- Write in clear, engaging language
- Preserve the speaker's voice and tone when quoting
- Include context when necessary for understanding
- Focus on the most impactful moments from the full conversation

## Selection Criteria:

- Choose highlights that span the entire episode length
- Balance different types of content (insights, quotes, tips, examples)
- Prioritize content that would make someone want to listen to the full episode
- Include any "aha moments" or surprising revelations

Return as a JSON array of strings:
["First key insight with specific detail", "Memorable quote that captures main theme", "Actionable tip listeners can use immediately", "Surprising fact or revelation", "Important conclusion or lesson learned"]
