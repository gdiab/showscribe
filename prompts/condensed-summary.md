# Condensed Summary Generation

Create a comprehensive but condensed summary of this podcast transcript that captures all the essential information needed for generating show notes. This summary will be used to create titles, guest bios, and social media content.

## Requirements:

**Extract and include:**

- Main topic and theme of the episode
- Key discussion points and arguments
- Guest name(s) and their background/expertise
- Important insights, conclusions, or takeaways
- Notable quotes or memorable moments
- Any products, services, or resources mentioned
- Call-to-actions or next steps mentioned

**Format:**

- Write in clear, structured paragraphs
- Include guest information prominently
- Maintain the chronological flow of key points
- Target length: 1,000-2,000 words (condensed but comprehensive)

**Focus on information that would be needed to:**

- Write an engaging episode title
- Create a guest biography
- Generate social media captions
- Understand the main value proposition of the episode

Do not include:

- Detailed quotes (save for highlights generation)
- Minute-by-minute breakdown
- Filler conversations or tangents
- Technical details that aren't central to the main message
